# 首轮结论：不推广当前学习 Router，保留研究与验证框架

2026-10-27，独立分支 `codex/rfc0001-bm25-first`。
本轮达到“交付当前候选的完整研究证据”的目标，**没有达到预先声明的质量—成本改进目标**，也没有完成整个 RFC-0001。
不修改默认 Router，不向 GitHub 发布本轮研究 PR，不改 RFC-0004 PR #7，不关闭服务器。

## 关键发现

1. 改进 Router 相对原规则能提高效果，但通过增加向量调用换取质量。dev 分组外层 nDCG@10
   从 0.662823 到 0.727548；调用率从 46.24% 到 88.97%。这不是准确率与速度同时提高。
2. 相对固定 hybrid，主方案 dev 节省 11.03% 调用，损失 0.004913，经验上界 0.006821。
   满足本轮 .01 质量界，但没有达到 30% 节省；.002 严格预算下联合方案外层上界 0.002331，也未通过。
3. 48 条预先固定的 dev 查询、每条每策略3次、k=100 的真实 HTTP：模型没有可靠加速证据。
   平均差值 +1.16 ms，配对95%区间 [-2.44,4.68]；不能把少10.4%的向量调用直接写成端到端加速。
4. 冻结模型在另外256条 CMedQA 查询上的迁移损失达0.025875，超过 .01 预算；调用节省20.31%仍不到30%。
   这批查询在本轮模型冻结后按固定规则选出，未用于再训练/选阈值。它仍是已观察过的20k抽样语料上的受条件评测，非新语料或官方全量benchmark。
5. 当前动作范围存在瓶颈：在997条dev上，用 qrels 事后在同一 BM25/hybrid 候选之间逐查询择优，
   nDCG@10仅0.739567，仍低于纯dense的0.772847。对这些冻结结果，任何仅选择这两个动作的策略都无法达到纯dense均值。
   这是当前两个动作的事后参考，不是所有检索系统的上界，不是可上线方法，也不代表别的数据必然如此。

## 真实 HTTP 成本

RTX4090、BGE CUDA、原DiskIndex常驻内存，单并发，真实HTTP返回100条，包含编码/向量/融合/渲染/JSON与传输。
48条dev按预声明哈希选取；各策略3次，每条查询的策略顺序固定随机打乱；每策略3次预热。
共720条测量请求，全部成功、无fallback。共享reader/encoder/backend是控制条件，不代表多租户、冷启动或高并发生产结论。
这里的质量是训练后模型在成本工作负载上的观测，**泛化结论使用上面的外层结果及下面迁移结果**。

## 固定模型迁移

从原始固定revision的CMedQA查询中排除历史512条ID、历史Du/MMarco/T2及已选查询的近重复（NFKC字符bigram Jaccard>=.8），
按冻结哈希取256条普通自然语言、在原20k语料中有正例的查询。
排除2745条在此子语料无正例的查询、512个历史ID、3个显式约束查询；其余按256上限截取，未根据检索分数筛选。
追加审计覆盖历史工作区全部12个queries*.jsonl文件、8634条记录，256条中没有达到.8阈值的近重复。
将完整历史文件枚举纳入准备入口后重跑，生成的256条查询与qrels字节完全一致。
这种答案可达条件及受限qrels改变了任务分布，不能当作官方3999查询/100001文档全量成绩。

## 失败分析与后续判断

在997条外层预测中，联合策略漏触发54条真实增益>.01的查询，241次调用没有带来nDCG提升，
11次跳过恰好选中了比hybrid更好的lexical。这里“无nDCG提升”不等于其他指标也无收益。
迁移集中有明确的“模型判词法充分、实则dense+RRF更好”的案例：例如关于碘131治疗甲亢的查询，
BM25/模型nDCG为0，hybrid为0.4307。只是公开数据集检索判例，不作医学解答。
仅凭头部分差、集中度及IDF不能稳定判断额外语义召回的收益；域偏移进一步恶化。

建议保留：可见信息受限的特征接口、分组嵌套选择、严格绑定的JSON推断、真实HTTP与迁移验证、Unicode JSONL修复及证据审计。
不建议直接默认合并：当前Ridge阈值/权重、宣称满足30%节省或普遍质量提升的结论。
后续可讨论：更充分的合法训练样本、词法top文档的匹配覆盖等新特征、真实成本目标；
但必须重新登记dev探索，不能用这256条结果反复筛特征。更换融合/允许纯dense动作应另经RFC-0002/0003协商，独立消融。
正式风险控制还缺独立校准及适用理论；不把本轮经验界包装成CRC。
