# RFC-0001 新一轮目标与执行计划

建立日期：2026-10-27（Asia/Shanghai）。本轮用户授权：按已认领计划重新制定目标并探索。
工作分支：`codex/rfc0001-bm25-first`，起点为已拆分的 `e356d97`；RFC-0004 PR #7 不变。

## 目标

在先完成 BM25 的前提下，只使用查询及词法统计，判断是否调用 dense + 原有等权 RRF。
交付可复算的研究和可替换原型，找到可信质量—成本改进，或记录充分的否决证据。
不保证必有正收益，不把更换阈值包装成原创，不改变默认生产策略，不自动关机。

## 阶段与验收

1. 文献与设计：核验 6–10 篇论文来源、方法、决策信息、监督与成本，至少两份方案卡及选型记录。
2. 数据和实验冻结：区分已观察 dev、已观察 test/迁移数据；保存 ID/文件/配置摘要和分组。
   目前 Du dev/test、MMarco、512 条 CMedQA 均为历史已观察，不声称它们是全新独立留出。
   使用 dev 内分组嵌套验证；新鲜最终验证需团队另行冻结合法数据后完成。
3. 主线特征与基线：固定 candidate_k=200、原 BM25、等权 RRF c=60、固定 embedding/ANN。
   比较 lexical、hybrid、dense、rules-v1，以及选中的 BM25-first 改进。
   不使用 query embedding、dense 分数、相关标签或“是否向量有收益”等线上不可见信息作为决策特征。
4. 研究原型：先研究可解释规则与轻量线性/小树收益预测；后者只作本地研究，正式采用须与团队确认。
   保留现有默认行为。用显式接口注入原型，记录特征规格、策略版本、模型与索引绑定。
5. 验证与消融：dev 的分组外层验证评估包含特征/超参/阈值选择的完整过程；内层决定候选。
   质量以相对固定 hybrid 的绝对 nDCG@10 损失为主，辅以 Recall/MRR/MAP。
   主研究预算在看新结果前固定为平均损失单侧经验上界 <= .01，向量调用减少 >=30%。
   同时报 .002 严格预算敏感性；这两个值是研究设置，未获团队正式验收批准，不作统计保证。
   近似上界为 mean(loss)+1.645*SE；配对 bootstrap 作描述性区间，不把“不显著”当等效。
   真实 HTTP 平均/p50/p95、Router耗时与向量尝试率分开测量，不能用候选重放时间代替在线收益。
6. 交付：计划/来源、特征/模型、划分/完整选择记录、逐查询决策、真实成本、失败分析、测试与复现命令。
   不自动发布新的研究 PR 或评论；先保留本地可审阅成果。

## 停止/调整条件

重复使用数据只能支持探索性结论；未获团队确认的数据和方法，不部署为默认或写成最终验收完成。
若预算/跨域目标不满足，保留现有策略并输出否决证据，继续能独立推进的基线/可复现性工作。
磁盘不足时复用只读索引/候选，禁止擅自删除历史产物或以语料前缀冒充全量。

## 本轮执行顺序与完成条件（重新制定）

Goal 工具现已可用，已按用户最新要求正式创建本轮目标；此前的旧目标占用已解除。
首轮997条dev上的嵌套验证已作为探索记录保留：联合方案约11.0%调用节省，未达到30%目标。
这些数字是新目标的已知起点，不再写成待验证的假设。

接下来按以下顺序执行：

1. 审核8篇文献与A/B方案卡，以及特征、分组、模型导出和约束保护测试。
2. 保持 FREEZE.json 指定的模型SHA256不变，先完成48条dev查询×3次真实HTTP测试，k=100。
   同时比较lexical/dense/hybrid/现有rules/冻结改进Router；报告平均、p50/p95、路由耗时与调用率。
3. 依照已冻结的排除/抽样规则构建至多256条额外CMedQA查询；不依据新结果重挑查询或调参。
   使用已有20k语料的真实双索引；若没有可用向量产物，先复用已固定文档编码，按实际成本重建，
   但不改变语料范围/embedding。不将受条件抽样的迁移结果冒充官方全量benchmark。
4. 汇总质量/成本、消融、失败查询与局限。满足预算时提供可供审阅的候选；不满足则保留默认并给出否决依据。
   完成代码和复现材料的独立本地提交，不自动发布新的PR/评论；RFC-0004 PR #7不变，服务器不关机。

本轮完成指“足够评估当前候选的研究包已交付”，不要求强行得到正收益，也不声称整个RFC-0001已完成。
正式共享接口、团队批准预算与最终独立数据仍是后续协作事项。
