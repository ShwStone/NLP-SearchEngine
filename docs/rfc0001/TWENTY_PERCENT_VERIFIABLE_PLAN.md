# Router 20% 可验证探索计划（2026-10-30 更新）

本文件覆盖旧计划中的“当前进展”。历史测量保留，不代表当前代码或目标已经通过。
Goal 保持 active；不发布 PR、不修改 RFC-0004、不关机。

## 固定验收条件

主基线继续使用本轮最初冻结的 fixed equal-RRF hybrid；在同查询、同语料上计算
`(new - baseline) / baseline`，不替换弱基线。分组嵌套外层开发和全新独立确认
必须分别同时满足 nDCG@10、Recall@10 严格超过 20%，各指标配对查询组
bootstrap 95% 增量区间下界为正，路由动作非恒定，真实 HTTP p95 比值不超过
1.05。报告 fixed dense、上一版 frozen Router、动作数量及代码/模型/数据哈希。

## 先纠正证据

旧 pre-BGE cascade 的全局 OOF 被用于外层训练门控，无法保证与外层验证标签
隔离；HTTP 审计用均值基线代替逐查询配对基线；旧预选“新确认集”各与已消费
BGE 确认重叠 17 条，且 freeze 在选集后被修改。最终门控未在全开发集拟合，
线上模型加载及候选批次也存在偏差。上述旧 cascade 证据全部撤回，禁止用于验收。
细节见 `artifacts/rfc01/twenty-percent/PREBGE_EVIDENCE_CORRECTION.json`。

历史第一份 BGE 确认的 +38.75%/+20.60% 和 p95 比值 1.09052 保留为失败测量，
其标签不进入训练。旧预选两集保留排除记录，不能重新当作全新确认集。

## 阶段一：候选与批次一致性（已完成）

用完整 BGE24 TensorRT FP16、batch20、length256 对真实 dense28/dense40 评分。
每个候选池按内部数值 docid 排序，与线上完全一致；保存源代码和引擎哈希。
训练只读取 raw29 白名单、当前 BGE4、当前 BGE 语义支持6及 BM25 查询统计，
禁止继承 GTE 分数或 GTE 参照特征。

## 阶段二：真正嵌套的模型与门控（执行中）

对每个 5 折外层训练子集，在其内部用 3 折产生门控训练所需的动作结果；
每个动作结果的超参数又仅在该动作的训练子集内用 3 折选择。之后在完整外层
训练子集选型、重训动作模型，外层验证组只做一次预测。保存全部模型及明确的
训练/验证/允许范围。独立审计重放每个选择、动作、排名和配对 CI。

## 阶段三：依结果选择下一步

1. 若2499外层质量不达标，不运行HTTP/确认；先分解候选缺失与候选内排序
   损失。仅登记有明确机制的新实验，避免不断扫描门槛或消费确认集。
2. 若质量达标，实现与本次真实嵌套动作完全一致的新运行时，不复用被撤回的
   legacy final loader。全量重放外层Top10、动作；同轮对照真实HTTP延迟。
3. 开发全部门槛通过后，用全开发分组重新选型和拟合最终动作及门控，不能
   复制fold0。训练查询回放仅验证实现一致性，不作为质量泛化证据。

### 2026-10-30 结果

2499 条严格嵌套实验的 raw/calibrated 路由 Recall 为 +19.9685%。加入
训练隔离的非线性 gain gate 后为 nDCG +33.5335%、Recall +20.0909%，
独立审计通过，但完整 HTTP p95 比例 1.06568。将 heavy 预算预声明为 60%
后 Recall 降至 +19.9336%；70% 后 Recall +20.1258%，但 HTTP p95 比例
1.13729。所有方案均未进入确认；详细数据见 `PREBGE_2499_RESULTS.md`。

当前问题已从“开发质量”收敛为“BGE40 重排成本/候选召回”：在没有新分数
和嵌套证据前，不得直接使用历史 seq192/adaptive160 logits。

## 阶段四：一次性全新确认

代码完成后冻结全部传递代码、模型、引擎、环境、语料及完整暴露清单；清单
必须包括所有已消费确认和旧预选失效集合。覆盖审计通过后才按预声明规则
选择全新查询，禁止选集后修改freeze或重新计算它来掩盖改动。先完成全部
HTTP请求，再打开标签；逐查询配对CI、动作与延迟全部独立重建。

只有全部条件通过才将Goal标记complete并执行约定关机。任何失败均保留
证据并保持目标未完成；本次新确认尚未开始，服务器保持运行。
