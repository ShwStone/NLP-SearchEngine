# 方案卡与首轮选型

共同设置见 GOAL.md：BM25-first、candidate_k=200、原等权 RRF c=60，两个动作仅为 BM25 / dense+RRF。
目标是质量—成本权衡，不同时改索引、embedding、融合或 reranker。

## A：可解释多信号规则（主对照）

假设：词表覆盖高、头部分差大且查询不太长时，BM25 已足够；其余请求 dense。
输入仅为查询长度/词项数、词法命中、df/IDF 和已完成 BM25 的分数。
规则 `skip_dense = coverage>=c and relative_gap>=g and n_terms<=t and hits>=2`。
内层分组验证选择 c∈{.7,1}、g∈{.1,.25,.5,.75}、t∈{4,12}；16 个预声明候选。

无需拟合权重，阈值校准仍使用 dev 标注，不能称为“完全无监督”。成本为已有 df 查询与头部聚合，
可解释且无模型依赖。实现量小。失败风险：分差不代表语义完整、单条命中缺少分差、长尾/域偏移。
对照 rules-v1 和规则消融。若质量界不满足，退回固定 hybrid；不改变默认规则。

## B：轻量增益预测（研究原型）

假设：查询/词法统计能预测 `gain = nDCG10(hybrid)-nDCG10(BM25)`，比绝对 QPP 更符合动作选择。
不是新提出的机器学习算法，而是已有 QPP/选择性检索思想的项目适配。
17 个特征：查询长度/项数/字符组成、词表覆盖与 IDF/df、头部 BM25 分数均值/CV、相对分差、熵、集中度。
不计算 query embedding，不读取 dense 结果或标签作为线上特征。

候选为 StandardScaler+Ridge(alpha∈{1,10,100})、小树(depth/leaf∈{2/30,3/30,4/50})。
路由 `use_dense = predicted_gain > threshold`；无 BM25 命中强制请求 dense。
阈值网格在代码声明；外层 5 组、内层 4 组，**整个模型/特征族/阈值选择在内层**。
在经验质量损失界内最大化调用节省，外层再判断是否达到至少30%的验收目标。
比较全特征、查询/语料特征、仅得分特征、规则族与联合选择。中小 CPU 训练，线上无需 sklearn。

原型只有17维线性或小树，序列化为验证过的 JSON；绑定特征版本、索引、embedding、ANN和融合。
风险：997条已观察 dev 可能不足，收益多为0、难预测，重复探索偏差，跨域失效。
失败时保留负结果及固定 hybrid，不承诺学习方法一定优于规则。

## C：正式风险/成本控制（本轮暂不采用）

以真正独立校准集、正部质量损失、实际向量成本建立风险感知决策；理论约束需另行推导，
不能把带符号差值/经验 t 界包装成 CRC。需要团队批准划分和预算，当前缺少干净最终留出，
所以只保留方向，本轮不宣称实现 conformal 或端到端硬延迟保证。

## 当前决策

先并列实现 A/B，通过 dev 内完整嵌套选择验证；保留固定 hybrid 作为不满足约束时的后备。
不采用 dense-first 主线，不根据已观察 test 的分数挑特征/阈值。
